# Wiedza o wariantach silnika

`knowledge/models/<model-key>.json` przechowuje potwierdzone informacje o wariantach silnika i źródła tych informacji. Każdy model ma osobny plik.

`engineClaims` dostarczają aliasów nazw używanych przez klasyfikator przy rozpoznawaniu silnika w tytule, opisie i danych portalu. Źródła pozostają przypięte do twierdzeń, żeby można było sprawdzić ich podstawę. Karta wiedzy nie zastępuje kryteriów z `config/models/<model-key>.json`, które określają kwalifikujące roczniki, ceny, przebieg i warianty.
